# Microsoft Entra ID | IT Support Labs

A hands-on technical portfolio documenting my practical learning in Microsoft Entra ID, Identity and Access Management (IAM), and cloud-based IT administration.

This repository focuses on real-world IT Support and Service Desk scenarios, including user onboarding, group management, authentication, access control, and troubleshooting.

## About This Project

The goal of this project is to develop practical Microsoft Entra ID administration skills through a series of structured, hands-on labs.

Each lab is designed around a simulated business scenario and documents the configuration steps, verification process, challenges, and key learnings.

## Lab 01 — User Creation and Group Management

**Scenario:** A company requires user accounts and departmental groups for employees working in IT, Sales, and Human Resources.

**Tasks completed:**
- Created three employee user accounts in Microsoft Entra ID.
- Created three departmental groups: IT, Sales, and HR.
- Assigned employees to groups based on their respective departments.
- Practised navigating the Microsoft Entra admin center.

**Skills practised:** User Provisioning, Group Management, Identity Administration, Microsoft Entra ID.

Detailed implementation steps and screenshots will be available in the individual lab documentation.

## Documentation Approach

Each lab will include:

1. **Objective** — What the lab aims to achieve.
2. **Business Scenario** — The IT support situation being simulated.
3. **Implementation** — Steps performed in the admin center.
4. **Verification** — Evidence used to confirm the configuration.
5. **Troubleshooting** — Issues encountered and their resolution, if applicable.
6. **Key Learnings** — Technical concepts and practical skills gained.

## Learning Objectives

Through these labs, I aim to build practical experience in:

- Microsoft Entra ID administration
- Identity and Access Management (IAM)
- User onboarding and offboarding
- Security group and access management
- Authentication and Multi-Factor Authentication (MFA)
- Role-Based Access Control (RBAC)
- Sign-in troubleshooting and technical documentation

## Disclaimer

All activities are performed in a personal learning environment using simulated business scenarios and test user accounts. No real organisational identities or production systems are involved.
